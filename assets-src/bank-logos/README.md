# โลโก้ธนาคาร

ไฟล์ในโฟลเดอร์นี้มาจากแพ็กเกจ [thai-banks-logo](https://github.com/casperstack/thai-banks-logo) (ISC License)
ตั้งชื่อตาม id ใน `src/core/accounts.js` แล้ว `npm run icons` จะคัดลอกไปที่ `public/assets/banks/`
ธนาคาร/ผู้ให้บริการที่ไม่มีไฟล์ที่นี่ จะใช้ป้ายสีประจำ + ตัวย่อที่วาดเอง (badgeSvg)

โลโก้เป็นเครื่องหมายการค้าของแต่ละธนาคาร ใช้เพื่อบอกว่าบัญชีไหนเป็นของธนาคารอะไรเท่านั้น
อยากเปลี่ยนรูป: วาง PNG สี่เหลี่ยมจัตุรัส (พื้นโปร่งใส) ชื่อเดียวกันทับ แล้วรัน `npm run icons`
