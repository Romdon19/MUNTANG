# สเปกออกแบบหน้า "ติดตั้งครั้งแรก" (LIFF)

ภาพ `1-welcome.png` … `7-done.png` (ไม่มีหน้า 6 เพราะเป็นแค่นายหัวหมุนหมุน) ในโฟลเดอร์นี้คือหน้าจอปัจจุบันขนาดจริง 390 × 844 pt (@3x = 1170 × 2532 px)
วางเป็นเลเยอร์ล่างสุดใน Figma / Canva แล้วออกแบบทับได้เลย

## 1. กรอบออกแบบ (Frame)

| อุปกรณ์ | Frame | พื้นที่เนื้อหา |
|---|---|---|
| **มือถือ (หลัก)** | **390 × 844** (iPhone 14/15) | กว้าง 354 (ขอบซ้ายขวา 18) |
| มือถือเล็ก (ตรวจว่าไม่ล้น) | 360 × 740 (Android) | กว้าง 324 |
| แท็บเล็ต | 768 × 1024 | กว้างสุด 600 ตรงกลาง |
| โน้ตบุ๊ก | 1280 × 800 | กว้างสุด 760 ตรงกลาง |

หน่วยในตารางนี้คือ pt (= px ที่ 1x) ออกแบบที่ 1x แล้ว export รูป @3x

- **ด้านบน:** LINE มีแถบหัว LIFF ของตัวเองสูงประมาณ 56 อยู่เหนือหน้าเรา ไม่ต้องวาดแถบนี้
- **ด้านล่าง:** เว้น 34 สำหรับแถบ Home ของ iPhone ปุ่มหลักวางเหนือระยะนี้

## 5. กติกา

- **ฟอนต์:** Kanit (หัวข้อ ปุ่ม ตัวเลข) + Anuphan (ข้อความรอง) เหมือนเมนูและแอป
- **ตัวหนังสือในปุ่ม การ์ด และหัวข้อ:** ให้โค้ดเป็นคนวาด อย่าฝังในรูป จะได้แก้คำ เปลี่ยนภาษา และขยายตามจอได้ ส่งรูปเฉพาะภาพประกอบ ไอคอน และมาสคอต
- **ไอคอน:** สไตล์เดียวกันทั้งชุด (สติกเกอร์เส้นดำหนาแบบในริชเมนู) วางกลางกรอบสี่เหลี่ยมจัตุรัส เว้นขอบ 8%
- **สีสถานะ:**
  - ตอนเลือก: รายจ่ายใช้พื้น `#FFF5CF` ขอบ `#141414` ส่วนรายรับใช้พื้น `#E9F5EE` ขอบ `#1D8A4C`
  - ตอนยังไม่เลือก: ไอคอนเป็นสีเทาโปร่ง 55% (ทำจากโค้ด ไม่ต้องส่งรูปสองแบบ)
- **ไฟล์:** PNG พื้นใส · ไอคอนแต่ละไฟล์ไม่เกิน 60KB · ภาพประกอบไม่เกิน 200KB
- **ส่งงาน:** ภาพหน้าจอที่ออกแบบ (ไว้ให้ผมจับระยะ สี และมุมโค้ง) + ไฟล์รูปตามชื่อในตาราง
